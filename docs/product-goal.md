# プロダクトゴール

前夜の回復(DOWN TIME / SLEEP TIME)を守れている状態を保ち、それが守れているかと、翌日の過ごし方・計画を、ひと目で分かるようにする。これによって、寝た後のパフォーマンスを最大化する。

## 背景

[README.md](../README.md) の「コア・ドメイン思想」に基づく。生産性の最大化ではなく、前夜の回復を最優先で防衛し、明日のパフォーマンスを最大化することを目指す。

## ゴールに含まれるもの

- **見える化**: DOWN TIME / SLEEP TIME が守れているか、翌日の過ごし方・計画が、ひと目で分かる。
- **守る仕組み**: DOWN TIME / SLEEP TIME を実際に守る(README の防衛ルール、動的スライド、タスクの伸縮制御など)。
